Genel bakış

Nasıl çalışır

PowerBuilder MCP, PowerBuilder çalışma alanınızı GitHub Copilot gibi MCP uyumlu AI istemcilerine bağlayan yerel bir stdio sunucusu olarak çalışır. Hiçbir kaynak kodu makinenizi terk etmez.

Sunucu ortam değişkenleri ve bir PowerShell giriş noktası ile yapılandırılır. PB_WORKSPACE_DIR, PB_ORCA_PATH, PB_MCP_LICENSE — run_mcp.ps1.
Adım 1

Önkoşulları kurun

  • PowerBuilder runtime'ınız ile uyumlu Windows ortamı
  • VS Code'da GitHub Copilot veya başka bir MCP uyumlu istemci
  • Yerel olarak kullanılabilir PowerBuilder çalışma alanı
  • PowerBuilder MCP binary / release paketi
PowerShellrun_mcp.ps1
$WorkspaceDir = "C:\projects\sales_app"
$OrcaPath     = "C:\path\to\native\runtime"
$LicenseKey   = "PBMCP-XXXX-XXXX-XXXX"

powershell -ExecutionPolicy Bypass -File .\run_mcp.ps1 ^
  -WorkspaceDir $WorkspaceDir ^
  -OrcaPath $OrcaPath ^
  -LicenseKey $LicenseKey
Adım 2

Copilot MCP'yi yapılandırın

PowerBuilder MCP'yi Copilot ayarlarınızda yerel bir stdio sunucusu olarak kaydedin.

settings.jsonVS Code → Copilot
{
  "github.copilot.chat.mcp.servers": {
    "powerbuilder": {
      "command": "powershell",
      "args": [
        "-ExecutionPolicy", "Bypass",
        "-File", "C:\PowerBuilderMCP\run_mcp.ps1"
      ],
      "env": {
        "PB_WORKSPACE_DIR": "C:\projects\sales_app",
        "PB_ORCA_PATH": "C:\path\to\native\runtime",
        "PB_MCP_LICENSE": "PBMCP-XXXX-XXXX-XXXX"
      }
    }
  }
}
Adım 3

Bağlantıyı doğrulayın

MCP sunucusunun doğru başlatıldığını doğrulamak için bir smoke test çalıştırın.

PowerShellsmoke test
powershell -ExecutionPolicy Bypass -File .\run_mcp.ps1 -SmokeTest

# expected outcome:
# initialize request succeeds and the MCP server responds

Ardından Copilot Chat'i açın ve daha ağır analiz promptlarını denemeden önce düşük riskli bir keşif sorusu sorun.

Gelişmiş

PowerBuilder MCP + SQL Server birlikte

PowerBuilder uygulamaları database-first'tir. DataWindow'lar SQL gömer, iş kuralları stored procedure'larda yaşar ve şemayı anlamak her Copilot önerisini ciddi şekilde iyileştirir. İpucu: PowerBuilder MCP'nin yanında SQL için ikinci bir MCP sunucusu çalıştırın, böylece Copilot hem uygulama nesnelerinizi hem de konuştukları veritabanını görür.

settings.jsonİki MCP sunucusu
{
  "github.copilot.chat.mcp.servers": {
    "powerbuilder": {
      "command": "powershell",
      "args": ["-ExecutionPolicy", "Bypass", "-File", "C:\PowerBuilderMCP\run_mcp.ps1"],
      "env": {
        "PB_WORKSPACE_DIR": "C:\projects\sales_app",
        "PB_ORCA_PATH": "C:\path\to\native\runtime",
        "PB_MCP_LICENSE": "PBMCP-XXXX-XXXX-XXXX"
      }
    },
    "mssql": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-mssql"],
      "env": {
        "MSSQL_HOST": "localhost",
        "MSSQL_PORT": "1433",
        "MSSQL_DATABASE": "sales_app_dev",
        "MSSQL_USER": "pbmcp_reader",
        "MSSQL_PASSWORD": "*****"
      }
    }
  }
}
Neden işe yarıyor: Copilot artık bir DataWindow'un gömülü SQL'ini gerçek tablo şemasıyla çapraz referanslayabilir. Hangi kolonlar tabloda yok diye sorduğunuzda tahmin etmek yerine gerçekten kontrol edebilir.
Kritik

SQL erişimi için güvenlik desenleri

AI asistanlarına veritabanı erişimi vermek bir hak değil, bir ayrıcalıktır. Her kurum bunu sorgulayacaktır ve sorgulamalıdır. İşte güvenli şekilde yapmanın yolu:

Yapın

  • ✓Read-only kullanici: sadece db_datareader, yazma islemlerine acik DENY
  • ✓Sadece dev veritabani: Asla Copilotu productiona baglama
  • ✓Ayri MCP: SQL kendi surecinde calisir, PowerBuilder MCP icinde degil
  • ✓Sema onceligi: Veriden once tablo/kolon kesfi
  • ✓Denetim izi: Profiler veya Extended Events ile tum sorgulari logla

Yapmayın

  • ✗sa veya admin credentials kullanma
  • ✗Production veritabanlarina baglanma
  • ✗db_owner veya yazma rolleri verme
  • ✗SQL calistirmayi PowerBuilder MCPnin icine gomme
  • ✗Credentialsi paylasilan repolarda plaintext saklama
SQL — read-only kullanıcı oluşturmaT-SQL
-- Create a read-only user for AI-assisted analysis
-- Run this on your DEVELOPMENT database, never production

CREATE LOGIN pbmcp_reader WITH PASSWORD = 'StrongPass!2025';

USE sales_app_dev;

CREATE USER pbmcp_reader FOR LOGIN pbmcp_reader;

-- Read-only: can SELECT, can see schema, cannot write
ALTER ROLE db_datareader ADD MEMBER pbmcp_reader;

-- Explicitly DENY write operations
DENY INSERT, UPDATE, DELETE, ALTER, DROP TO pbmcp_reader;

-- Verify
SELECT permission_name, state_desc
FROM sys.database_permissions
WHERE grantee_principal_id = USER_ID('pbmcp_reader');
sqlcmd alternatifi: Ortamınız MCP SQL sunucularına izin vermiyorsa, şemayı sqlcmd ile dışa aktarın, çalışma alanınızda bir .sql dosyası olarak kaydedin ve Copilot'un bunu bağlam olarak okumasına izin verin.
sqlcmd ile şema keşfideveloper workstation
-- sqlcmd: run from developer workstation
-- Useful when MCP SQL server is not available

sqlcmd -S localhost -d sales_app_dev -U pbmcp_reader -P "*****" -Q "
  SELECT t.name AS table_name,
         c.name AS column_name,
         ty.name AS data_type
  FROM sys.tables t
  JOIN sys.columns c ON t.object_id = c.object_id
  JOIN sys.types ty ON c.user_type_id = ty.user_type_id
  WHERE t.name LIKE 'order%'
  ORDER BY t.name, c.column_id
"
Referans

Tool referansı

  • list_libraries — Calisma alanindaki PBL kutuphanelerini listele
  • list_objects — Belirli bir kutuphanedeki nesneleri incele
  • export_object — Bir nesneyi analiz edilebilir kaynak formatina disa aktar
  • import_object — Kaynagi kutuphaneye geri derle/import et
  • search_objects — Pattern ve opsiyonel nesne tipine gore ara
  • parse_datawindow — Disa aktarilan DataWindowlardan SQL, tablo ve kolonlari cikar
  • analyze_dependencies — Nesne ve function referanslarini belirle
  • find_nested_datawindows — Ic ice DataWindow kullanimini bul
  • analyze_dynamic_sql — EXECUTE IMMEDIATE, PREPARE/EXECUTE ve dynamic cursorlari tespit et; SQL degisken atamalarini izleyerek tablo ve kolonlari cikar
Destek

Sorun giderme

  • PowerBuilder runtime yolu yerel makinede geçerli olmalıdır.
  • İşlemci mimarisi uyumluluğunu kontrol edin (32-bit vs 64-bit).
  • Lisans anahtarınızın geçerli ve süresi dolmamış olduğunu doğrulayın.
  • PB_WORKSPACE_DIR'in geçerli bir .pbw dosyasına işaret ettiğinden emin olun.
Kurumsal destek için: deneme aktivasyonu, lisans doğrulama, on-prem dağıtım ve güvenli iş istasyonu kurulumu — hesap ekibinizle iletişime geçin.

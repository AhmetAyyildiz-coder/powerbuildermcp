STEP 01 Prerequisites

Before you begin, ensure you have the following installed on your development machine:

  • ✅  PowerBuilder 12.5 (or later) with a valid license
  • ✅  Visual Studio Code with the GitHub Copilot extension
  • ✅  MCP support enabled in Copilot Chat settings
  • ✅  Windows OS (required for the PowerBuilder runtime)
ℹ PowerBuilder MCP runs as a local stdio server. No cloud connection required — your source code never leaves your machine.

STEP 02 Install the MCP Server

Download the PowerBuilder MCP server binary and place it in a directory on your PATH. On Windows:

PowerShell
# Download the latest release
Invoke-WebRequest -Uri "https://powerbuildermcp.com/releases/pb-mcp-latest.zip" `
  -OutFile "$env:LOCALAPPDATA\pb-mcp.zip"

# Extract and add to PATH
Expand-Archive -Path "$env:LOCALAPPDATA\pb-mcp.zip" `
  -DestinationPath "$env:LOCALAPPDATA\pb-mcp"

[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:LOCALAPPDATA\pb-mcp", "User")

Verify the installation:

Terminal
pb-mcp-server --version
# → PowerBuilder MCP Server v1.0.0

STEP 03 Configure Copilot

Add the MCP server to your Copilot configuration. Open VS Code settings (Ctrl+,) and search for Copilot MCP, or edit the settings JSON directly:

settings.json
{
  "github.copilot.chat.mcp.servers": {
    "powerbuilder": {
      "command": "pb-mcp-server",
      "args": [],
      "env": {
        "PB_WORKSPACE": "C:\\Projects\\MyApp\\myapp.pbw"
      }
    }
  }
}
💡 Tip: You can point multiple workspaces by adding additional entries. The server will index them on first connection.

STEP 04 Verify the Connection

Restart VS Code, open Copilot Chat, and type a test query:

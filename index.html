FAQ

Frequently asked questions

Everything teams ask before adopting PowerBuilder MCP.

Does it work with GitHub Copilot?

Yes. PowerBuilder MCP is an MCP server that integrates directly with GitHub Copilot in VS Code. Copilot calls structured tools to inspect libraries, export objects, parse DataWindows, and analyze dependencies.

Can it inspect DataWindows?

Yes. It exports DataWindow source and parses it to extract SQL queries, tables, columns, retrieval arguments, and nested DataWindow references.

Is source code kept local?

Yes. PowerBuilder MCP runs as a local stdio server. Your source code stays on your machine and is never sent to any external server.

Does it support enterprise environments?

Yes. It supports on-premise deployment, team licensing, and audit-friendly workflows — designed for banks, insurance companies, and large organizations.

Is it suitable for migration planning?

Absolutely. It helps identify heavily reused business rules, tightly coupled UI logic, complex DataWindows, and service extraction candidates — a strong foundation for phased modernization.

What PowerBuilder versions are supported?

PowerBuilder 12.5 is currently supported through the native PowerBuilder runtime interface. Additional versions are on the roadmap.

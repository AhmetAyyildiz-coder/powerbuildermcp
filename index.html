Example

Copilot reads your PBLs
like any modern codebase

Once configured, Copilot can explore objects, list dependencies, extract source code, and suggest refactors — all through standard MCP tool calls.

copilot-conversation.md
// User asks Copilot:
Find all DataWindows in the sales module that reference
the "customer_id" column and list their retrieval arguments.

// Copilot calls MCP tools:
pb_list_objects("sales.pbl", "datawindow")
  → d_customer_list, d_order_summary, d_invoice_detail

pb_get_source("sales.pbl", "d_order_summary")
  → returns full DataWindow syntax with retrieval args:
    arguments:
      ("order_id", "number")
      ("customer_id", "number")

// Copilot responds:
Found 2 DataWindows referencing "customer_id":

  d_order_summary (sales.pbl)
    retrieval args: order_id, customer_id
    SQL: WHERE orders.customer_id = :customer_id

  d_invoice_detail (sales.pbl)
    retrieval args: invoice_id, customer_id
    SQL: WHERE invoices.customer_id = :customer_id

Would you like me to suggest a shared retrieval argument
signature for consistency?
Capabilities

Everything Copilot needs
to work with PowerBuilder

Built on the native ORCA interface — not screen scraping, not file parsing. Direct programmatic access to the PowerBuilder object model.

01
Object Exploration
List all objects in a PBL by type — windows, DataWindows, functions, structures, user objects. Navigate the object hierarchy programmatically.
02
Source Extraction
Export full source code of any PowerBuilder object through pborca.dll. Copilot sees your actual code, not guesses.
03
Dependency Mapping
Identify which objects reference others. Understand the blast radius of changes before you make them.
04
Search & Analysis
Search across all PBLs for specific patterns, function calls, SQL statements, or column references. Find dead code and duplication.
05
Compile & Validate
Trigger incremental builds through ORCA. Let Copilot verify its own suggestions compile before presenting them.
06
Modernization Insights
Generate migration reports. Identify C# equivalents for PowerScript patterns. Plan incremental modernization roadmaps.
How It Works

Three steps. No changes
to your PowerBuilder setup.

STEP 01
Install the MCP Server
Add PowerBuilder MCP to your Copilot configuration. Point it at your workspace and pborca.dll location.
STEP 02
Open Copilot
Launch VS Code or your IDE with Copilot Chat. The PowerBuilder tools are now available alongside standard Copilot capabilities.
STEP 03
Ask Anything
Copilot reads your PBLs, understands PowerScript and DataWindow syntax, and helps you refactor, debug, and modernize.
Installation

Up and running
in under two minutes

Add the MCP server configuration to your Copilot settings file.

settings.json — Copilot MCP Configuration
{
  "github.copilot.chat.mcp.servers": {
    "powerbuilder": {
      "command": "pb-mcp-server",
      "args": [],
      "env": {
        "PB_ORCA_PATH": "C:\\Program Files\\Appeon\\PowerBuilder 12.5\\pborca.dll",
        "PB_WORKSPACE": "C:\\Projects\\MyApp\\myapp.pbw"
      }
    }
  }
}

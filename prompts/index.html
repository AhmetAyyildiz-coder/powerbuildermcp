Prompt Library

Copy-paste prompts
that actually work

Tested prompt patterns for common PowerBuilder analysis and modernization tasks. Paste these into Copilot Chat with the PowerBuilder MCP server connected.

Workspace discovery

Get a full inventory of your PowerBuilder application structure.

List all libraries in this workspace, then show me a summary of object types in each library (windows, DataWindows, user objects, functions).

DataWindow audit

Find DataWindows with complex or risky SQL patterns.

Search for all DataWindows that use "customer_id" as a retrieval argument. For each one, export the source and extract the SQL query, tables, and columns. Flag any that have nested DataWindows.

Dependency tracing

Map what depends on what before refactoring.

Export w_order_entry and analyze its dependencies. List every function, user object, and external reference it calls. Then check if any of those are also used by other windows.

Migration planning

Prioritize what to modernize first.

Find all global functions and rank them by how many objects reference them. Identify the top 5 most coupled components that would be hardest to extract into a service layer.

Safe edit planning

Plan a controlled change with full context.

I need to add a "status" column to d_order_summary. Find every object that references this DataWindow, check what retrieval arguments it uses, and tell me what else needs to change.

Dead code detection

Find objects nobody references.

List all user objects in shared.pbl. For each one, search the entire workspace to see if any other object references it. Report any that have zero references.
